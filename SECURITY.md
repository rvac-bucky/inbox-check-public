# Security reports

Do not submit secrets, private emails, or exploitable details in public issues. Use the repository's private vulnerability-reporting feature if enabled; otherwise ask a maintainer for a private reporting channel without posting the sensitive details.

Report the affected version, a sanitized reproduction, the violated trust boundary and expected behavior. The application is experimental screening—not a replacement for email authentication, malware defenses or human review. Supported release: the current main branch. No response-time SLA is promised.
